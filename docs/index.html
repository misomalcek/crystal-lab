crystal-lab

Point it at a folder. It builds a 3D crystal from the files, embeds the text on your machine, and lets you retrieve, hop, and ask.

Download for Apple Silicon Source

macOS on Apple Silicon. Version 0.4.2. The disk image is about 134 MB and the app is 188 MB after install. Not notarized: the first launch is right-click, then Open. Intel and Windows are not in this build. MIT. No account, no telemetry. Nothing leaves the machine unless you set an endpoint yourself.

What you can do with it

A folder of notes

Markdown, text, HTML, and the text layer of a PDF become one crystal. The same name in two files is one node.

A small repository

Rust, TypeScript, JavaScript, Python, Go, Java, and C/C++ are read as text. Import edges are drawn when the target file is in the folder.

Retrieve across files

Three ranked lists — vector, lexical, and a walk along relates-to — fuse by rank. Reciprocal rank fusion, k = 60.

Ask your own model

An OpenAI-compatible endpoint, cloud or local, can name types and answer from the folder. Without one, the graph and retrieve still run.

How a folder becomes a crystal

  • Pick a folder. Files, imports, and sibling links draw first. Ingest hangs the text chunks off each file.
  • Names are extracted without a model. One normalized spelling is one node. mentions ties it to the files. relates_to links two names that share a chunk.
  • A spelling fold is kept as a merge note. Names that embed as near-duplicates but do not share a spelling stay two nodes, flagged conflicts_with. A flag is recoverable. A silent merge is not.
  • Click a node. The card shows type, files, neighbors by weight, the passages, betweenness next to degree, and the raw payload.
  • Hub spread (LinLog), from 1 to 15, pushes connected nodes apart and widens the chunk ring around each file. Glow, from 0 to 1.5, scales the edge haze. Each folder remembers its own pair.
  • Hop is one step. Blast is two. Ask can call those walks, plus retrieve, when the endpoint accepts tool calls.

Limits

This is free, and it is for a folder of notes or a small repository. It is not for a massive codebase. The stop is in the app, not in Qdrant. Past the cap, ingest finishes and the log says what was cut.

  • 400 chunks for the whole folder, 80 for one file, about 1 800 characters a chunk.
  • 400 file nodes drawn. 10 000 files walked.
  • One text file up to 2 MB. One PDF up to 32 MB, text layer only.
  • Images are nodes, with no OCR. Office files are counted, not parsed.
  • node_modules, target, dist, .git, and hidden directories are skipped.

Concepts and the stack

  • Tauri 2, Rust, a small Vite front end, three.js for the verse.
  • Qdrant and nomic-embed-text v1.5 (768 dimensions) travel inside the app. llama.cpp serves the embedder. Ports are chosen free at launch.
  • Reciprocal rank fusion, Cormack, Clarke, and Buettcher, 2009. Fusion reads rank, never the cosine and never the edge weight.
  • The third list is the Zep / Graphiti pattern: walk relates_to by weight, then fuse. This build does that rank fusion only, not the extra MMR or node-distance stages.
  • Hub spread is degree-scaled repulsion, the LinLog idea: a hub pushes harder than a leaf. Betweenness is shown on the card as a bridge score, and it is not used to delete nodes.
